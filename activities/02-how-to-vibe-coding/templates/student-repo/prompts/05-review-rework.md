# 阶段 5：预审、返工与现场变更

收到预审问题后，先复现，不要直接接受 AI 或审核官的结论。

推荐提问：

> 对每个发现项先判断能否复现、影响哪条验收标准、根因是什么，再提出最小修复和回归范围。不要为了让测试变绿而削弱断言。修复后给出前后证据，并更新相关文档。

现场变更推荐提问：

> 这是一个新需求。先说明它改变了哪些假设、数据和接口，哪些现有测试必须继续通过，以及时间盒内的最小方案。不要立即编码；先提交影响分析和调整后的计划。

你必须产出：

- 发现项复现记录。
- 返工提交与回归证据。
- 现场变更影响分析、新测试和独立提交。
- `docs/RETROSPECTIVE.md`。

核验：能够解释为什么改、为什么这样改、AI 哪里可能出错，以及哪些风险仍然存在。
