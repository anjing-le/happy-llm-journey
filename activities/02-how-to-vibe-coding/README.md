# 第二期 · 如何成为 AI 时代的超级上下文

持续提升自己，善用并积累最佳实践，与 AI 一起把事情做好。

- **自己的提升**：知识广度与关键点深度、业务理解、判断力和审美。
- **最佳实践的运用与积累**：组织知识、方法和工具，与 AI 协作，再沉淀经验。

两条线在同一任务中推进。首轮从 coding 开始，长期不局限于编程。
