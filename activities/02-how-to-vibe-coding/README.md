# 第二期 · 如何成为 AI 时代的超级上下文

**持续提升自己，善用并积累最佳实践，与 AI 一起把事情做好。**

- **自己的提升**：拓展知识广度，在关键问题上深入，提升业务理解、判断力、审美和从反馈中学习的能力。
- **最佳实践的运用与积累**：选择适用的方法、工具、Skill 和知识资源，与 AI 协作完成任务，再沉淀可复用经验。

两条线围绕同一个任务推进：想法与目标 → 方案与上下文 → 协作实现 → 判断与验证 → 交付反馈 → 复盘与迭代。

“超级上下文”不等于记住所有知识；它包含个人能力，也包含寻找、组织和运用外部资源的能力。活动长期不局限于编程，首轮从 coding 场景积累和验证。
