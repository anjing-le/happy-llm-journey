# 如何成为 AI 时代的超级上下文 · 活动设计

设计初稿，待试跑。这里的“超级上下文”指个人的理解与判断，以及寻找、组织和运用外部资源的能力。

## 两条主线

- **自己的提升**：理解业务，拓展知识，在关键问题上深入；练习判断、审美与反馈学习。
- **最佳实践的运用与积累**：选择适用的方法、工具、Skill 和知识，组织协作、验证结果，留下可复用经验。

自身能力帮助选择方法，实践结果暴露能力缺口，也检验方法是否有效。首轮以 coding 为载体，先选一个适合参与者基础的任务。

## 实践过程

1. **明确目标**：记录起点、要解决的问题、范围与成功标准。
2. **准备方案**：补必要知识，整理上下文，确定第一个可验证步骤。
3. **协作实现**：与 AI 分步推进，检查结果，解释关键取舍。
4. **判断与改进**：结合测试、体验和反馈修正成果，练习质量判断。
5. **交付与复盘**：让他人能复现结果，对照起点总结提升，提炼方法并尝试复用。

每一步都关注「自己学到了什么、方法是否有效」。按任务需要往返调整，不强制全套 PRD、UI、部署或独立文档。卡住时检查目标、信息、方法与能力限制，再决定补充、换法或缩小范围，不依赖未来模型升级完成当前交付。

## 最小交付

- 一个可复现的成果，附验证证据与已知限制。
- 一段成长复盘：认识改变了什么，关键判断有什么依据。
- 一条方法草稿：适用问题、做法、效果与限制；复用结果如实记录。

验收同时看成果与个人理解；能运行不等于学会。必要时通过一次小变更检验。具体标准随选题确定。
