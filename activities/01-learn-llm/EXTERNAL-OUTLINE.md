# 外部参考 · Agent 开发六步

来源：用户提供的一张「Agents 开发 6 步闭环」课程提纲截图。课程作者、链接与实际教学效果尚未确认。以下是便于后续比较的归纳，属于参考材料，不是本期活动的正式路线。

1. **模型接口契约**：SDK 与模型初始化；消息和响应结构；流式输出、推理控制、本地模型接入及配置管理。
2. **系统提示词**：封装模型调用，编写与渲染系统提示词，注入动态信息，并处理流式响应。
3. **会话**：保存多轮历史、接入模型调用、持久化会话、管理上下文长度。
4. **工具调用**：定义和校验工具，处理调用与结果回填、错误、安全边界及测试。
5. **封装工具**：通过参数模型、装饰器和注册机制，减少重复的工具定义与调度代码。
6. **ReAct 循环**：让模型在推理、调用工具、观察结果之间循环，明确停止条件、上下文管理、风险控制与调试方式。

这份提纲适合作为**动手实现最小 Agent 循环**的参考。它较少涉及我们第一期已规划的任务编排、数据获取与更新、Harness 的恢复和资源约束、系统化评估。截图中提到的 Ollama、Pydantic 和固定循环写法，也要按实际任务选择，不能直接当作必修步骤。

后续比较其他资料时，以「能否帮助参与者完成、解释并验证一个 Agent」为取舍依据；缺什么补什么，不按课程章节堆全套知识。具体题目和实践顺序仍需试跑确定。
