# 第三期 · 一群人如何做好 vibe coding

让团队建立适合自己的 AI 协作方式，并在持续交付中不断完善。

覆盖全新、有一定历史包袱和历史包袱较重的团队。共用原则与方法，根据目标、人员、系统现状和变更风险选择实践路径。

## 了解与设计

了解团队现状与协作问题，设计最小必要的上下文组织和协作方式。

- 明确目标、成员分工、系统依赖与主要问题。
- 确定知识、约定和决策放在哪里，人与 AI 如何查找、维护。
- 约定任务分工、交接与验证方式，选择一个可控的真实任务开始。

设计到足以实践即可，不要求先整理齐全部上下文。

## 实践与完善

围绕真实任务协作和交付，在反馈中持续维护上下文、调整协作方式。

- 实践分工、交接、集成与验证，发现理解偏差和协作阻碍。
- 根据结果更新知识与约定，改进方法，继续维护和迭代项目。
- 判断有误时回到「了解与设计」，沉淀经实践支持的团队经验。

成果包括任务交付，以及在任务中验证、可继续沿用的协作方式。具体选题与完成标准待定，尚未试跑。
