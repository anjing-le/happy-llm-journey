# 数据、内容与系统边界

## 允许进入作业仓库

- 已脱敏且获得授权的题目描述、模拟数据和占位配置。
- 学员为本作业原创的代码、测试、设计说明和运行证据。
- 不包含个人账号内容的 Codex 协作摘要和本人判断说明。

## 禁止进入作业仓库

- 简历、联系方式、身份证明、真实姓名映射和其他学员信息。
- Token、API Key、密码、Cookie、私钥、个人 Codex 会话或账号共享信息。
- 真实雇主代码、客户数据、生产日志、商业秘密及未获授权的第三方素材。
- 组织者私密反馈、隐藏用例、参考答案、评分细节和未脱敏作业。

发现疑似敏感内容时应停止传播，撤销相关凭证，并由组织者决定清理方式。仅删除最新文件不足以清除 Git 历史。

## 活动声明

- 本活动用于项目实践和能力反馈，不承诺就业、录用、薪资或面试结果。
- Codex 是协作工具；学员对提交内容、验证结果和技术判断负责。
- 不共享或中转个人 Codex 账号、会话、凭证或 API Key。
- 本目录公开活动说明与题面草案。学员提交、个人评价和组织者内部审核材料另行私有保存。
