# Happy LLM Journey

持续积累 AI 时代的知识与实践方法，通过活动引导实践，让反馈推动改进。

![知识、实践方法与活动的关系](assets/route.svg?v=20260918-1)

| 入口 | 你可以在这里做什么 |
| --- | --- |
| [知识](knowledge/README.md) | 理解关键概念，检索依据、来源与案例。 |
| [实践方法](practices/README.md) | 使用我们从实际经历中归纳的方法，了解适用条件与验证边界。 |
| [活动](activities/README.md) | 围绕具体任务，选择方法、动手实现、检验结果并反馈。 |

## 我们积累什么

知识底座保留我们的理解、关键关系和可靠来源；实践方法保留独特的经验抽象及其依据；活动把这些内容组织成可参与、可验证的过程。

知识支撑方法，方法指导活动。活动中的问题和反馈，也会反过来修正方法、补充知识。
