## 如何使用

面向企业级项目的个人 vibe coding 最佳实践。

把本文链接或正文交给你的 Agent，选择一种用法：

- **制作个人 Skill**：结合你的基础、协作习惯与项目需要，由 Agent 解释关键选择，与你一起定制。完成后说明何时使用、如何调用，并用一个小任务体验。
- **直接开始**：不预先创建 Skill，围绕当前任务使用同一套方法；需要时再补充个人约定。

给 Agent：先读取全文，简短说明用途与当前缺口。用户希望创建 Skill 就引导定制，希望处理编程任务就直接使用；意图不明时再询问，只补问必要信息。无法读取正文时请用户提供，不能凭链接猜测；方法未就绪时，不把草稿当作完整实践。后续根据实际结果提出修订，保留用户的定制。

## 定制个人 Skill

从你当前的一项开发任务开始。Agent 先读取可用的项目约定，了解你的目标、基础、协作习惯和最想改善的问题，只补问必要信息。涉及个人 Skill 的关键选择，先解释作用与取舍，再由你调整；把确认的约定整理成精简草稿，用真实任务体验后修订。

Skill 保留可复用的个人方法，项目约定按需引用。待验证的做法标明状态，再根据实际结果决定保留、修改或删除。
