## 迭代方式

- 先按列表积累，每项内容优先使用一个独立 Markdown 文件，在本页链接并写一句话说明；不提前划分类别。
- 条目标明实际状态，例如探索中、已验证或待修订，保留失败和限制，不把草稿视为已验证的方法。
- 内容引用[知识底座](../knowledge/README.md)中的依据；[活动](../activities/README.md)按任务需要引用方法。
- 当若干条目形成清晰体系后，再讨论归类并提取到对应文件夹；同时更新列表及引用链接。
- 列表是内容入口，不是待办清单；未完成的任务不作为成品收录。
