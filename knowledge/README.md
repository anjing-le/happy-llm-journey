# 知识

以应用为目标，积累工程与算法的关键概念、理解、来源和案例，供人和 AI 按需检索。

## 分类

- [工程](engineering/README.md)：结合传统软件工程与 AI 时代的设计、开发、验证和运行方式。
- [算法](algorithms/README.md)：理解模型与算法的原理、能力、限制及评估方法，支撑实际应用中的选择。

## 轻量 KV 组织

KV 是内容组织约定，不要求另建数据库或一套 JSON：

- **K：稳定的条目标识**，例如 `agent-loop`。不把期数或分类写死到 key 里，后续移动分类仍保留 key。
- **V：一份 Markdown 内容**，保存我们对这个问题的理解、整理、来源和必要案例；标题用直观的中文。
- 本页及各分类 README 用列表维护「key → 内容链接：一句话说明」。一项内容只维护一份，活动与方法引用它。

工程、算法内部先平铺 Markdown 文件，不预建更多目录。暂时无法判断归属的条目可直接放在 `knowledge/` 下，登记在下面的待归类列表；不为归类阻塞记录，也不额外建设收集系统。

内容多了再按真实需要调整，移动时保留 key、更新索引与引用。没有整理需求就继续平铺。传统应用工程与 LLM 应用工程在同一知识底座逐步积累，详细知识地图尚待讨论。

## 内容原则

保存我们自己的理解、关联和实践依据，通用知识优先引用可信来源。记录内容的未确认之处，不把模型生成的解释直接作为已验证结论。不一次性批量生成教材、目录或占位文章。

人与 AI 的相关内容按主要问题暂归工程或算法，暂不单列分类。经过实践归纳的具体做法放入[最佳实践](../practices/README.md)。
