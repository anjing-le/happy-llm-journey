# 知识

以应用为目标，保存我们自己的理解、来源与案例，供各自的 Codex 按问题检索；使用者不必先了解内部分类。

- [工程](engineering/README.md)：传统软件工程与 AI 应用的设计、开发、验证和运行。
- [算法](algorithms/README.md)：模型与算法的原理、能力、限制和评估。

## 如何积累

- 轻量 KV：一个稳定 key（如 `agent-loop`）对应一份 Markdown，入口列出链接和一句话说明。
- 文件先平铺；归属不明先放本目录，记在下方，内容多了再整理。移动时保留 key、更新链接。
- 按实际问题逐条积累；通用知识引用来源，不批量生成教材。具体做法放入[最佳实践](../practices/README.md)。
