# 知识

以应用为目标，积累工程与算法的关键概念、理解、来源和案例，供人和 AI 按需检索。

## 分类

- [工程](engineering/README.md)：结合传统软件工程与 AI 时代的设计、开发、验证和运行方式。
- [算法](algorithms/README.md)：理解模型与算法的原理、能力、限制及评估方法，支撑实际应用中的选择。

## 组织方式

当前只设工程、算法两个分类，不单设「人与 AI」。各分类通过 README 列出具体 Markdown 内容，先逐篇积累，不预建更深的分类目录。

每份内容确定一个主要归属，交叉主题通过相对链接关联，不重复维护。区分事实、推测与待验证理解，通用资料优先引用来源。知识为方法提供依据，经过实践归纳的做法放入[最佳实践](../practices/README.md)。
